All files in this folder contain synthetic demonstration data. In Data import choose the file, leave mapping as {}, select Synthetic / test data, then Import and evaluate. transactions.csv and transactions.json contain the same six events; use one format. The last event triggers velocity, amount and travel. Re-imports report duplicates. ml-holdout-sample.csv comes from the downloaded public synthetic dataset. It has no transaction location/device data, so those rules are unavailable.
